# Web Calculator

A basic web calculator with a modern UI, built using only HTML, CSS, and JavaScript.

## Features

Planned features for future implementation:

- Basic arithmetic operations: addition (+), subtraction (-), multiplication (*), division (/)
- Clear function to reset the calculator
- Decimal point support
- Responsive, modern design

## Getting Started

### Prerequisites

A modern web browser such as:

- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

### Running the Calculator

Simply open `index.html` in your browser. No build step or installation required.

**Option 1: Direct file opening**

1. Navigate to the project folder in your file explorer
2. Double-click `index.html`, or
3. Right-click `index.html` and select "Open with" your preferred browser

**Option 2: Using a static server (optional)**

If you prefer to use a local development server, any simple static server will work:

- VS Code Live Server extension
- Python: `python -m http.server 8000`
- Node.js: `npx serve`

Note: A static server is entirely optional. The project works perfectly when opened directly from the filesystem.

## Technology

This project is intentionally simple and beginner-friendly, using only:

- **HTML5** for structure
- **CSS3** for styling
- **Vanilla JavaScript** for interactivity

No build tools, package managers, or external frameworks are required.
